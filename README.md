# Caja Boutique

Aplicación web progresiva (PWA) para punto de venta de boutique.

## Publicación gratuita

Este repositorio se puede publicar en GitHub Pages.

1. Coloca en la raíz del repositorio los cinco archivos originales del ZIP: `index.html`, `manifest.json`, `service-worker.js`, `icon-192.png` y `icon-512.png`.
2. En GitHub, abre **Settings → Pages** y en **Build and deployment → Source** selecciona **GitHub Actions**.
3. Configura un flujo de GitHub Actions para publicar los archivos estáticos, o usa la opción de despliegue disponible en Pages.
4. La dirección esperada será `https://cesarmtz1525-hash.github.io/caja-boutique-pwa/`.

## Nota sobre datos

Antes de usarla con ventas reales, verifica cómo guarda los datos y haz copias de seguridad. El almacenamiento local del navegador no sincroniza automáticamente entre teléfonos y puede perderse si se borran los datos del navegador. Publicar la app no añade una base de datos ni sincronización en la nube.
